Does success in one app transfer to another app with the same function?

Recent agents exceed 90% success on live Android benchmarks — but every task there is bound to one app. Deployment is different: a user says "set an alarm for 7:30" and expects it to work in whatever clock app is installed. Below, the instruction stays identical; only the app changes.

What is AnyAppBench?

A category-controlled, live Android benchmark. We define 10 functional categories corresponding to common mobile goals, write 10 reusable task templates per category with deterministic verifiers, and instantiate every template across structurally diverse apps that support the same user-facing goal — 11 original AndroidWorld apps and 41 new apps chosen for interface diversity.

How do we diagnose why an agent fails to generalize?

Beyond success rate, every failed trajectory is attributed to a cause. We run agents twice — from the raw user instruction, and with externally provided app-agnostic sub-goals — then a human-validated LLM-as-judge pipeline labels each failure.

How do I evaluate my agent?

1
Set up the environment

A headless emulator image plus scripts that install all 52 pinned APKs and pre-grant their runtime permissions.

2
Implement one interface

Your agent receives a screenshot and an accessibility tree, and returns a JSON action. Wrappers for common agents are included.

3
Run & diagnose

Get success per task–app pair, the transfer gap per category, and judge-attributed failure modes.

git clone https://github.com/AnyAppBench/benchmark.git
cd benchmark/benchmark
pip install -r requirements.txt

# Check the suite resolves: 52 runnable apps, 520 task-app pairs.
python scripts/verify_catbench_task_support.py

# C1, direct execution.
CATBENCH_CONDITION=c1 python scripts/run_catbench_5cat_matrix.py \
    --models MY-AGENT --n_task_combinations 3 --task_random_seed 30 --run_id c1

# Attribute the verifier-failed rollouts to a failure mode.
python scripts/classify_catbench_failures.py --manifest runs/c1/manifest.json

# Per-model and per-app tables.
python scripts/report_catbench_5cat_results.py
